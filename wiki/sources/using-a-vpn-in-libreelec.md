Want to use your [VPN](https://droix.net/vpn-introduction) connection within the LibreELEC operating system, but not sure how to?

### Krypton (LibreELEC 8.x)

* Boot into LibreELEC.  
  ![DROIX LibreELEC Combined Splash Screen](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180404_0-e1500570712679-1-296x300.png)
* Click the System icon at the top (a cog above “Movies”).  
  ![Kodi 17 LibreELEC Settings Icon Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180652_0-1-300x169.png)
* Select the “File manager” entry then “Add Source”.  
  ![Kodi 17 LibreELEC System File Manager Icon Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180659_0-1-300x169.png)  
  ![Kodi 17 LibreELEC System File Manager Add Source Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180705_0-1-300x169.png)
* Click the top box, type in  **http://dbmc.droidbox.co.uk/repo**  for the address, then click OK.  
  ![Kodi 17 LibreELEC System File Manager Add Source URL Entry Box](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180712_0-2-300x169.png)  
  ![Kodi 17 LibreELEC System File Manager Add Source URL Entry Keyboard](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180720_0-1-300x169.png)  
  ![Kodi 17 LibreELEC System File Manager Add Source URL Entry Keyboard URL Entered](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180735_0-2-300x169.png)
* Select the 2nd box and label it (anything you like) then click OK again.  
  ![Kodi 17 LibreELEC System File Manager Add Source Label Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180748_0-2-300x169.png)  
  ![Kodi 17 LibreELEC System File Manager Add Source Label Keyboard](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180802_0-1-300x169.png)
* Click OK in the last window, and now head to Kodi’s homescreen and click the Add-ons menu.  
  ![Kodi 17 LibreELEC System File Manager Add Source Info Entered, OK Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180813_0-1-300x169.png)  
  ![Kodi 17 LibreELEC Kodi Homescreen Add-ons Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180835_0-1-300x169.png)
* Now click the Add-on Browser icon (an open cardboard box, top left of the screen).  
  ![Kodi 17 LibreELEC Kodi Homescreen Add-ons Browser Icon Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180846_0-1-300x169.png)
* Select “Install from zip file”.  
  ![Kodi 17 LibreELEC Kodi Add-ons Install From ZIP Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180855_0-1-300x169.png)
* Click on the entry with the label you created a moment ago.  
  ![Kodi 17 LibreELEC Kodi Add-ons Install From ZIP Source Selection](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180904_0-1-300x169.png)
* Click on repository.zomboided.plugins-1.0.0.zip ,wait a few moments for the process to complete, a notification will likely appear.  
  ![Kodi 17 LibreELEC Kodi Add-ons Install From ZIP File Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180911_0-1-300x169.png)
* Now click on “Install from repository”, then the Zomboided entry.  
  ![Kodi 17 LibreELEC Kodi Add-ons Install From Repository Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180947_0-1-300x169.png)  
  ![Kodi 17 LibreELEC Kodi Add-ons Install From Repository Repo Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180955_0-2-300x169.png)
* Click “Services” and select the VPN Manager for OpenVPN entry, then click the Install button.  
  ![Kodi 17 LibreELEC Kodi Add-ons Install From Repository Repo Entered Services Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_182635_0-1-300x169.png)  
  ![Kodi 17 LibreELEC Kodi Add-ons Install From Repository Repo Entered VPN Manager for OpenVPN Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_182642_0-2-300x169.png)  
  ![Kodi 17 LibreELEC Kodi Add-ons Install From Repository Repo Entered VPN Manager for OpenVPN Install Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_182648_0-1-300x169.png)
* Once complete, a pop up message and a notification will appear confirming the installation, click OK.  
  ![Kodi 17 LibreELEC Kodi Add-ons Install From Repository Repo Entered VPN Manager for OpenVPN Install Confirmed Notification](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_182656_0-1-300x169.png)![Kodi 17 LibreELEC VPN Manager for OpenVPN VPN Installation Confirmed](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183729_0-1-300x169.png)
* You can now skip down to the “***Installed? Let’s Configure!***” section below

### Jarvis (LibreELEC 7.x, OpenELEC 6.x)

* Turn the device on and ensure you are not in Android!  
  ![DROIX LibreELEC Combined Splash Screen](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_180404_0-e1500570712679-1-296x300.png)
* Click the “File manager” entry under the System menu on the far right (if using the default skin)  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN File Manager](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205148_0-1-300x169.png)
* Select “Add Source”![Kodi 16 LibreELEC VPN Manager for OpenVPN File Manager Add Source](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205259_0-1-300x169.png)
* Click the top box, type in  **http://dbmc.droidbox.co.uk/repo**  for the address, then click Done.  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN File Manager Add Source Click Address Box](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205307_0-1-300x169.png)  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN File Manager Add Source Address Entered Click Label Box](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205439_0-1-300x169.png)
* Select the 2nd box and label it (anything you like) then click Done again.  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN File Manager Add Source Enter Label Keyboard](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205454_0-1-300x169.png)
* Click OK in the last window, and now head to Kodi’s homescreen and click the System menu itself.  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN File Manager Add Source Address And Label Entered Click OK](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205517_0-1-300x169.png)![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205623_0-1-300x169.png)

  ![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu Add-Ons Area Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205632_0-1-300x169.png)  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu Add-Ons Area Install From ZIP Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205644_0-1-300x169.png)
* Click on the entry with the label you created a moment ago.  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu Add-Ons Area Install From ZIP Select Source](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205651_0-1-300x169.png)
* Click on repository.zomboided.plugins-1.0.0.zip .  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu Add-Ons Area Install From ZIP DROIX Repo Select ZIP](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205713_0-1-300x169.png)
* Wait a few moments for the process to complete, a notification will likely appear, now click on “Install from repository”, then the Zomboided entry.  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu Add-Ons Area Install From Repository](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205808_0-1-300x169.png)![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu Add-Ons Area Install From Repository Select Zomboided Repoi](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205817_0-1-300x169.png)

  ![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu Add-Ons Area Install From Repository Select Services](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205823_0-300x169.png)
* Select the VPN Manager entry, then click the Install button.  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu Add-Ons Area Install From Repository Select VPN Manager for OpenVPN](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205828_0-300x169.png)  
  ![Kodi 16 LibreELEC VPN Manager for OpenVPN System Menu Add-Ons Area Install From Repository Select Install](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205835_0-300x169.png)
* Once complete, a pop up message will appear confirming the installation, click OK and the configuration screen will appear.![Kodi 16 LibreELEC VPN Manager for OpenVPN Addon Installed Confirmation Notification](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205854_0-300x169.png)![Kodi 16 LibreELEC VPN Manager for OpenVPN Addon Installed Confirmation](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_205859_0-300x169.png)

### Installed? Let’s Configure!

### Kodi 17 LibreELEC Kodi Add-ons Install From Repository Repo Entered VPN Manager for OpenVPN Configuration First Area

In this example we will be using [IPVanish](https://www.ipvanish.com/droidbox/?a_aid=56793406edacd&a_bid=48f95966&chan=promo) , but there are also options for: AirVPN, BTGuard, Celo, CyberGhost, ExpressVPN, Hide.Me, Hide My Ass, HideIPVPN, Invisible Browsing VPN, IVPN, LimeVPN, LiquidVPN, NordVPN, Perfect Privacy, Private Internet Access (PIA), PrivateVPN, proXPN, PureVPN, RA4W VPN, SaferVPN, SecureVPN.to, Smart DNS Proxy, tigerVPN, TorGuard, TotalVPN, VanishVPN, VPN.ac, VPN.ht, VPN Unlimited, VPNArea, VPNSecure, VyprVPN, WiTopia, Windscribe or you can create all the settings manually for VPN companies not listed.

*Jarvis users (LibreELEC 7.x and OpenELEC) will find the different areas of this configuration are arranged horizontally, rather than vertically. The actual options and settings to configure remain the same.*

* Change the VPN Provider to IPVanish by clicking the up arrow at the end of the line. (More screenshots coming soon)  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN Configuration First Area VPN Provider](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183333_0-1-300x169.png)
* Enter your IPVanish **username** (not e-mail address) and password.  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN Configuration First Area Username](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183341_0-1-300x169.png)  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN Configuration First Area Username Entry Keyboard](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183412_0-1-300x169.png)  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN Configuration First Area Password](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183457_0-1-300x169.png)  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN Configuration First Area Password Entry Keyboard](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183511_0-1-300x169.png)  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN Configuration First Area Username And Password Entered](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183523_0-1-300x169.png)
* Now head to the VPN Connections area and click on the “First VPN Connection” entry. The first time will take a little longer whilst data is collected and the account is confirmed with IPVanish.  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN VPN Connections Area](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183552_0-1-300x169.png)
* Select the country and city you want your server to be based in. Don’t forget you can tap the Up arrow on your remote a couple of times to jump to the end of the list, and if you have Page Down on your keyboard, you can skip down the list quickly.  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN VPN Connections Country City Server Selection](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183625_0-1-300x169.png)![Kodi 17 LibreELEC VPN Manager for OpenVPN VPN Connections Country City Server Selection End Of List](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183633_0-1-300x169.png)
* A connection will now be set up, with details confirmed. Click the OK button and you will now find your data from with LibreELEC is not snooped upon, and geo-locked services in your home country will once again be available.  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN VPN Connections Creating Connection](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183646_0-1-300x169.png)  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN VPN Connections Connection Made Self Test](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183650_0-1-300x169.png)![Kodi 17 LibreELEC VPN Manager for OpenVPN VPN Connections Connection Made Test Results](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183655_0-1-300x169.png)  
  ![Kodi 17 LibreELEC VPN Manager for OpenVPN VPN Connections Connection Made Connection Confirmed](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20170720_183713_0-1-300x169.png)

If the repository is offline, you can download the ZIP file you need from [here](https://github.com/Zomboided/repository.zomboided.plugins/releases/download/1.0.0/repository.zomboided.plugins-1.0.0.zip). You can then copy it to your device (see <https://droix.net/copying-files-to-and-from-libreelecs-storage> for details). Instead of selecting the DROIX repository when “Install(ing) via ZIP”, click the “HOME FOLDER” entry, then to whichever folder you pasted into. Click the ZIP file and continue from the “Now click on Install from Repo” step above.

---

The steps above should work for any LibreELEC installation, unless a service has been disabled. Please note only some DROIX devices come with LibreELEC, those currently on sale are the [DROIX T8-S Plus v2](https://droidbox.co.uk/droidbox-t8s-plus-dualboot-android-libreelec-4k-amlogic-s812.html) and the [iMXQpro v2](https://droidbox.co.uk/droidbox-imxqpro-mxq-pro-best-android-tv-box-kodi-box-libreelec-amlogic-s905.html). Previous models featuring LibreELEC or OpenELEC include the DROIX T8-S, T8-S Plus v1 and the DROIX T8 Mini.

If you have an older device using OpenELEC, the steps above will still work, however there is an alternative approach you can follow at <https://droix.net/using-a-vpn-in-openelec> .
