Sometimes you have a button on your remote control that you don’t use. Whether it is a “Zoom” button, or a Subtitle shortcut, you may just not ever use the function assigned to it…

If you wish you could use that same button for a feature you do use more often, Innerlife is on hand with their Multilanguage Keymap Redefiner application. We should point out we don’t have any sort of association with the author of this application, we just wanted to share the free app with visitors! Although not updated in a long time, it still works and can help bring extra functionality to your controllers.  
![MKR Result in Google's Play Store Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/MKR-Result-in-Play-Store-Copy.png)

#### 

#### How to install

Open up the Play Store app on your device. If you’ve not done this before, please check <https://droix.net/first-run-of-googles-play-store/> for details.

![Multilanguage Keymap Redefiner Open Play Store](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/1-Multilanguage-Keymap-Redefiner-Open-Play-Store-300x169.png)

Click on the Search Bar at the top of the screen and enter *mkr* as your search.

![Multilanguage Keymap Redefiner Click Search Bar](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/2-Multilanguage-Keymap-Redefiner-Click-Search-Bar-1024x576.png)

![Multilanguage Keymap Redefiner enter MKR search term](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/3-Multilanguage-Keymap-Redefiner-enter-MKR-search-term-1024x576.png)

![Click Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/4-Click-Multilanguage-Keymap-Redefiner-1024x576.png)

Click on the Multilanguage Keymap Redefiner entry.

![Click Install Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/5-Click-Install-Multilanguage-Keymap-Redefiner-1024x576.png)

Click the Install button.

![Click Accept Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/6-Click-Accept-Multilanguage-Keymap-Redefiner-1024x576.png)

Click the Accept button

![Downloading Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/7-Downloading-Multilanguage-Keymap-Redefiner-1024x576.png)

The application will now download and install automatically

![Installing Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/8-Installing-Multilanguage-Keymap-Redefiner-1024x576.png)

Once installed you can click the Open button.

![Open Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/9-Open-Multilanguage-Keymap-Redefiner-1024x576.png)

The first time you open the application, you will need to enable (on Lollipop devices) and then select Multilanguage Keymap Redefiner as your default keyboard.

![Click Go To Language And Input Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/10-Click-Go-To-Language-And-Input-Multilanguage-Keymap-Redefiner-1024x576.png)

To do so, Click the Go To Language and Input button

![Click Current Keyboard Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/11-Click-Current-Keyboard-Multilanguage-Keymap-Redefiner-1024x576.png)

Click the Current Keyboard entry

![Click Choose Keyboards](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/12-Click-Choose-Keyboards-1024x576.png)

Click Choose Keyboards

![Click Language And Input Twice Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/13-Click-Language-And-Input-Twice-Multilanguage-Keymap-Redefiner-1024x576.png)

![Enable Turn On Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/14-Enable-Turn-On-Multilanguage-Keymap-Redefiner-1024x576.png)

Turn on the Multilanguage Keymap Redefiner entry

![Click OK Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/15-Click-OK-Multilanguage-Keymap-Redefiner-1024x576.png)

Click OK

![Showing ENABLED Multilanguage Keymap Redefiner Input Method](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/16-Showing-ENABLED-Multilanguage-Keymap-Redefiner-Input-Method-1024x576.png)

Go back one screen

![Click Current Keyboard Again Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/17-Click-Current-Keyboard-Again-Multilanguage-Keymap-Redefiner-1024x576.png)

Select Current Keyboard again.

![Click Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/18-Click-Multilanguage-Keymap-Redefiner-1024x576.png)

Select Multilanguage Keymap Redefiner.

![Showing Selected Multilanguage Keymap Redefiner Input Method](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/19-Showing-Selected-Multilanguage-Keymap-Redefiner-Input-Method-1024x576.png)

Go back two screens.

#### How to remap

![Click Add Mapping Multilanguage Keymap Redefiner App Open](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/20-Click-Add-Mapping-Multilanguage-Keymap-Redefiner-App-Open-1024x576.png)

Click Add Mapping

![Press Remote Button To Remap Multilanguage Keymap Redefiner](https://droix.net/wp-content/uploads/2016/09/21-Press-Remote-Button-To-Remap-Multilanguage-Keymap-Redefiner-1024x576.png)

Now press the remote control button that you do NOT want to use. This is the button which will be remapped to another function in a moment.

![Click 0 Entry Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/22-Click-0-Entry-Multilanguage-Keymap-Redefiner-1024x576.png)

Now click the 0 entry at the top, this will bring down the list of possible functions to assign.

![Some Of The Functions In Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/23-Some-Of-The-Functions-In-Multilanguage-Keymap-Redefiner-1024x576.png)

![Some More Functions In Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/24-Some-More-Functions-In-Multilanguage-Keymap-Redefiner-1024x576.png)

![Showing Configured Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/25-Showing-Configured-Multilanguage-Keymap-Redefiner-1024x576.png)

Your screen will now look a little different as the new function should be assigned

![Demonstration of Remapped Button Working Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/26-Demonstration-of-Remapped-Button-Working-Multilanguage-Keymap-Redefiner-1024x576.png)

Once set, return to another application and make sure the shortcut still works as intended.

If when you reboot the shortcut does not function any more, you will need to set Multilanguage Keymap Redefiner as your default input method again. This time make sure you only use the Return button to exit the screens where you select the default input method.

![MKR Entry in Google's Play Store Multilanguage Keymap Redefiner](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/MKR-Entry-in-Play-Store.png)
