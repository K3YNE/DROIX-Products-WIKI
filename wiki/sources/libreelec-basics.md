Have a device with the LibreELEC operating system, and aren’t sure how to use it? This post will guide you through configuring LibreELEC, both from the first-run Wizard and using a program add-on

The first time you turn the device on (or if the data is cleared), a Wizard will greet you when LibreELEC completes booting up.

![LibreELEC 8.0.2 Wizard First Screen Welcome](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Wizard-First-Screen-Welcome-300x169.png)

If you have other media devices on your network that run LibreELEC, you will want to change the Hostname (to something unique) on this screen by clicking it.

![LibreELEC 8.0.2 Wizard Second Screen Hostname](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Wizard-Second-Screen-Hostname-300x169.png)

If you have connected your device to your home network with an ethernet cable, you can click the Next button for each screen, after checking the connection has been recognized.

![LibreELEC 8.0.2 Wizard Third Screen a Networks Showing Ethernet Connection](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Wizard-Third-Screen-a-Networks-Showing-Ethernet-Connection-300x169.png)

If you will be using WiFi to connect to your network, click the name that matches your WiFi network and then select the Connect option.

![LibreELEC 8.0.2 Wizard Third Screen a Selecting WiFi Network](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Wizard-Third-Screen-a-Selecting-WiFi-Network-300x169.png)

![LibreELEC 8.0.2 Wizard Third Screen b Select Connect](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Wizard-Third-Screen-b-Select-Connect-1-300x169.png)

Type in your WiFi password and click OK. Make sure any letters are the COrRecT case, that the letter O doesn’t become confused with the number 0, and that i, l and 1 aren’t similarly confused for each other. If you do not know your WiFi password, look for a label or card on the bottom or side of your modem.

![LibreELEC 8.0.2 Wizard Third Screen c Password Entry Onscreen Keyboard](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Wizard-Third-Screen-c-Password-Entry-Onscreen-Keyboard-2-300x169.png)

If the password is accepted, a connection will be made and the state will change to “online”. You can now click the Next button.

![LibreELEC 8.0.2 Wizard Third Screen d Shows WiFi Connected](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Wizard-Third-Screen-d-Shows-WiFi-Connected-1-300x169.png)

The next screen shown will ask if you want to keep SSH and Samba enabled. The first allows you to remotely connect to your device, the second for sharing files over your network in a simpler manner.

![LibreELEC 8.0.2 Wizard Fourth Screen Services SSH Samba](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Wizard-Fourth-Screen-Services-SSH-Samba-2-300x169.png)

Having decided whether to keep them enabled, click the Next button and you will see the last screen of the Wizard. Click the Next button and Kodi is now ready for you to install your preferred repositories/add-ons. <https://DroidBOXForums.com> has areas for your model, Kodi in general, Add-ons and many other sections covering most interests.

![LibreELEC 8.0.2 Wizard Fifth Screen End](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Wizard-Fifth-Screen-End-2-300x169.png)

If you need to alter your network settings later on, you can do so via the LibreELEC Configuration Program Add-on. It can be found in the Add-ons area, specifically Program Add-ons.

![LibreELEC 8.0.2 Homescreen Add-ons Highlighted LibreELEC Configuration Showing](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Homescreen-Add-ons-Highlighted-LibreELEC-Configuration-Showing-2-300x169.png)

To check or modify your Ethernet settings, look for the “Wired” entry when looking at the Connections area.

![LibreELEC 8.0.2 LibreELEC Configuration b Connections Area Ethernet Connection](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-LibreELEC-Configuration-b-Connections-Area-Ethernet-Connection-2-300x169.png)

For WiFi, check it is enabled in the Network area. You can then head to the Connections area and click the name of your WiFi network. As with the Wizard, select Connect, and then enter your password carefully.

![LibreELEC 8.0.2 LibreELEC Configuration a Network Showing WiFi Already Enabled](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-LibreELEC-Configuration-a-Network-Showing-WiFi-Already-Enabled-1-300x169.png)

![LibreELEC 8.0.2 LibreELEC Configuration b Connections Area Selecting WiFi Network](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-LibreELEC-Configuration-b-Connections-Area-Selecting-WiFi-Network-2-300x169.png)

![LibreELEC 8.0.2 LibreELEC Configuration b Connections Area WiFi Network Select Connect](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-LibreELEC-Configuration-b-Connections-Area-WiFi-Network-Select-Connect-2-300x169.png)

![LibreELEC 8.0.2 LibreELEC Configuration b Connections Area WiFi Network Password Entry Onscreen Keyboard](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-LibreELEC-Configuration-b-Connections-Area-WiFi-Network-Password-Entry-Onscreen-Keyboard-2-300x169.png)

![LibreELEC 8.0.2 LibreELEC Configuration b Connections Area Showing WiFi Connected](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-LibreELEC-Configuration-b-Connections-Area-Showing-WiFi-Connected-2-300x169.png)

If you decide to start with a clean and empty Kodi once more, you can reset LibreELEC via the LibreELEC Configuration Program Add-ons. In the first area shown when you open the add-on (System), scroll down on the right hand side and select the Reset System Settings to defaults option. Do remember that you will lose all settings, downloads and favourites.

![LibreELEC 8.0.2 LibreELEC Configuration c System Area Reset LibreELEC Highlighted](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-LibreELEC-Configuration-c-System-Area-Reset-LibreELEC-Highlighted-2-300x169.png)

Some devices:

If you own a Dual Boot device, the following shows how to switch between the two operating systems.

From Android click (if present) the shortcut on the homescreen

![DROIX Switch Homescreen Switch To LibreELEC Icon](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/DroidBOXSwitch-Homescreen-Switch-To-LibreELEC-Icon-2-300x169.png)

Alternatively, via the application’s icon in the app drawer

![DROIX Switch App Drawer Switch To LibreELEC Icon](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/DroidBOXSwitch-App-Drawer-Switch-To-LibreELEC-Icon-2-300x169.png)

From LibreELEC back to Android again

This can be done via the Power/Standby symbol in Kodi’s homescreen (if using the default skin)

![LibreELEC 8.0.2 Switch To Android In Default Skin](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Switch-To-Android-In-Default-Skin-2-300x169.png)

![LibreELEC 8.0.2 Switch To Android In Default Skin Reboot To Android](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-Switch-To-Android-In-Default-Skin-Reboot-To-Android-2-300x169.png)

Or, again, via the LibreELEC Configuration program add-on

![LibreELEC 8.0.2 LibreELEC Configuration c System Area Reboot to Android](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-LibreELEC-Configuration-c-System-Area-Reboot-to-Android-2-300x169.png)

![Switching OS](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/Switching-OS-2-300x169.png)

If the device has a hard drive bay and the disk can’t be formatted in Android, you can format the drive in LibreELEC.

Head to the LibreELEC Configuration program add-on and the first area shown should be scrolled down. Make sure all other storage devices (USB thumb drive, memory cards etc) are disconnected, and then click the  Format your internal HDD entry.

![LibreELEC 8.0.2 LibreELEC Configuration c System Area Reboot to Android](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/LibreELEC-8.0.2-LibreELEC-Configuration-c-System-Area-Reboot-to-Android-1-3-300x169.png)

The steps above should work for any LibreELEC installation, older versions may look slightly different.

Please note only some DROIX devices come with LibreELEC, those currently on sale are the [DROIX T8-S Plus v2](https://droidbox.co.uk/droidbox-t8s-plus-dualboot-android-libreelec-4k-amlogic-s812.html) and the [iMXQpro v2](https://droidbox.co.uk/droidbox-imxqpro-mxq-pro-best-android-tv-box-kodi-box-libreelec-amlogic-s905.html). Previous models featuring LibreELEC or OpenELEC include the DROIX T8-S, T8-S Plus v1 and the DROIX T8 Mini.
