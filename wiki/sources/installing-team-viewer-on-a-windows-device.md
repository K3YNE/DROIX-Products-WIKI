Being able to connect to and control a device via the internet or your home’s network can really help with some stubborn technical issues.  
  
![TeamViewer](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/teamviewer-small1.png)

If you have been directed to this post and simply want DROIX to be able to connect to your Windows-based device, please follow the steps below.

If you want to be able to connect FROM your Windows powered device to other devices as well as receive remote control sessions, please click here.

#### Instructions for one-way help installation

So, to confirm, follow these steps if you just need to enable remote access to your DROIX device…

![1 TeamViewer QuickSupport Download](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/1-TeamViewer-QuickSupport-Download-300x169.png)

![2 TeamViewer QuickSupport Downloaded](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/2-TeamViewer-QuickSupport-Downloaded-300x169.png)  
Download [this](https://download.teamviewer.com/download/TeamViewerQS_en.exe) file on your device and run the “TeamViewerQS\_en.exe” file once the download completes.

![3 TeamViewer QuickSupport Opened](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/3-TeamViewer-QuickSupport-Opened-300x169.png)  
When asked if you want to allow QuickSupport to make changes, please select the Yes button.

![4 TeamViewer QuickSupport Running](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/4-TeamViewer-QuickSupport-Running-300x169.png)  
You will see a number (“Your ID”) and a password, please take a note of these and pass them to whoever will be checking your device.

![5 TeamViewer QuickSupport Connection Present](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/5-TeamViewer-QuickSupport-Connection-Present-300x169.png)  
If all has gone well you will find that whilst the QuickSupport application is open, you are able to receive a connection and have your model looked at.

#### Instructions for complete installation

![1 TeamViewer Download](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/1-TeamViewer-Download-300x169.png)

![2 TeamViewer Downloaded](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/2-TeamViewer-Downloaded-300x169.png)  
If you want to be able to control OTHER devices from your DROIX device running Windows, you will need to download [this](https://download.teamviewer.com/download/TeamViewer_Setup_en.exe) file, and then run the “TeamViewer\_Setup\_en.exe” file.

![3 TeamViewer Opened](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/3-TeamViewer-Opened-300x169.png)  
Click on the Personal / Non-commercial use entry, then the “Accept – finish” button

![4 TeamViewer Permission](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/4-TeamViewer-Permission-300x169.png)  
Select Yes button when asked if you want to allow QuickSupport to make changes.

![5 TeamViewer Installing](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/5-TeamViewer-Installing-300x169.png)

![6 TeamViewer Installed](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/6-TeamViewer-Installed-300x169.png)  
Allow the installation to complete and then click the Close button

![7 TeamViewer Running](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/7-TeamViewer-Running-300x169.png)  
As with the other installation method, you will see a code for “Your ID” and password. If you want people to connect to you, pass them this information and have the application running.

If you want to control other people’s devices, they will need to install QuickSupport or the full TeamViewer as well. Once you have *their* ID (a password will also be present for some installations) you can initiate a connection by typing the number into the Partner ID box.

#### NOTE – Windows Store Based Installs

You can also download and install TeamViewer via [Microsoft’s Windows Store](https://www.microsoft.com/store/apps/9wzdncrfj0rh). Click this link or search the store for TeamViewer and install it using the steps listed below. You may however need to register for a TeamViewer account if you use this installation method.

![1 TeamViewer Windows Store Trigger](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/1-TeamViewer-Windows-Store-Trigger-300x169.png)

![2 TeamViewer Windows Store Entry](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/2-TeamViewer-Windows-Store-Entry-300x169.png)  
In both cases, you should now see something similar to the screenshot above, press the Install button in the Store.

![3 TeamViewer Windows Store Downloading](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/3-TeamViewer-Windows-Store-Downloading-300x169.png)

![4 TeamViewer Windows Store About to Launch](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/4-TeamViewer-Windows-Store-About-To-Launch-300x169.png)  
You will be informed the app is downloading and retrieving data. After this completes, click the Launch button

![5 TeamViewer Windows Store Launched](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/5-TeamViewer-Windows-Store-Launched-300x169.png)

![6 TeamViewer Windows Store Location of your ID in Help](https://droix.net/knowledge-base/wp-content/uploads/sites/3/2021/11/6-TeamViewer-Windows-Store-Location-of-Your-ID-in-Help-300x169.png)  
As with the desktop application version of Team Viewer, you can both receive remote connections and initiate them.

![TeamViewer](https://droix.net/wp-content/uploads/2016/09/TeamViewer-300x300.png)
